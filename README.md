🚁 AI Drone Tracker

An AI-powered video analysis and drone tracking project built with Python, computer vision, and machine learning.

📌 Project Overview

AI Drone Tracker is a personal engineering project designed to analyze video footage, detect objects, track movement, and generate useful statistics.

The initial version will work with uploaded videos. Future versions will integrate with a physical drone and Raspberry Pi to collect flight telemetry and enhance aerial video analysis.

🎯 Project Goals

* Build an AI-powered video detection system.
* Detect cars, people, trucks, bicycles, and other objects.
* Track objects across video frames.
* Assign unique IDs to tracked objects.
* Count detected objects.
* Generate video analysis reports.
* Build a dashboard to visualize results.
* Eventually integrate GPS and drone flight data.
